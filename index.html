Frequently Asked Questions

How do I access Google Drive resources? ▼

All Google Drive links require BUP email authentication. Make sure you're logged into your BUP Google account before clicking on any Drive links.

What should I do if a link is not working? ▼

If any resource link is broken, please report it using the Feedback button. You can also check the main Google Drive folder for the most up-to-date resources.

How often is this website updated? ▼

This website is updated regularly with new resources and announcements. Check back frequently for the latest materials.
