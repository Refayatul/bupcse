# BUP CSE Resources

to view the live site : https://bupcse.pages.dev/

BUP CSE Resources is a website that provides academic resources for students of the Computer Science & Engineering department at Bangladesh University of Professionals (BUP). It offers a wide range of resources, including course materials, routines, and other helpful documents, organized by batch and semester. The website also features a search functionality, resource filtering, PWA support, and a dark mode toggle for enhanced user experience.

Installation

To install BUP CSE Resources as an app, follow these steps:

1.  On Android devices, open the website in Chrome and tap the "Add to Home Screen" button.
2.  On iOS devices, open the website in Safari and tap the "Share" button, then select "Add to Home Screen".

Usage

To use BUP CSE Resources, follow these steps:

1.  Select your batch from the batch selection section.
2.  Browse the resources by semester in the "All Semesters" section.
3.  Use the search bar to find specific resources, courses, or keywords.
4.  Filter resources by type using the filter buttons.
5.  Add resources to your bookmarks for easy access.
